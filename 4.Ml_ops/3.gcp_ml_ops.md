# Agent Platform

### ML Metadata: 
ML Metadata (MLMD) is used to track, store, and manage metadata about ML workflows ( workflow means pipeline + stages )
   * Data versioning → which dataset/version was used.
   * Model versioning → which model/version was created.
   * Input / Output artifacts → datasets, models, checkpoints, etc.
   * Parameters → hyperparameters/configuration used during execution.
   * Evaluation results → accuracy, precision, recall, loss, etc.
   * Execution details → pipeline/stage execution and status.
   * Lineage → relationship between data → training → model → evaluation.
