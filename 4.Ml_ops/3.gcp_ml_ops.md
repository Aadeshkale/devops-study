# Agent Platform

### Pipeline 
* Pipeline automates and orchestrates the end-to-end ML workflow by connecting multiple stages such as data preparation, training, evaluation, and deployment
* In GCP Agent Platform Pipelines, pipelines can be defined using **Kubeflow** Pipelines (KFP) or **TensorFlow** Extended (TFX). 
---
### Model Registry 
* Model Registry is used to register, manage, version, and track trained ML models. It does not primarily store the model files itself.
* The actual model artifacts are stored in an artifact location such as:
   * Cloud Storage (GCS) → model files/artifacts
   * Artifact Registry → container images used for custom model serving/training
---   
### Dataset 
* Dataset is a managed ML data resource used to organize, manage, version, and provide data for ML training and evaluation.
* Supported data sources depend on dataset type:
    * BigQuery → Tables/views
    * Cloud Storage → CSV, JSONL, images, etc.
    * DataFrames → Supported for certain multimodal workflows
    * Versioning → Helps track different dataset versions and identify which dataset/version was used for training.
    * Lineage → Helps track the relationship between datasets and ML workflows.
---
### ML Metadata: 
* ML Metadata (MLMD) is used to track, store, and manage metadata about ML workflows ( workflow means pipeline + stages )
* Basically, it tracks the metadata of each pipeline step / ML stage and the relationships between them. 
    * Data versioning → which dataset/version was used.
    * Model versioning → which model/version was created.
    * Input / Output artifacts → datasets, models, checkpoints, etc.
    * Parameters → hyperparameters/configuration used during execution.
    * Evaluation results → accuracy, precision, recall, loss, etc.
    * Execution details → pipeline/stage execution and status.
    * Lineage → relationship between data → training → model → evaluation.
