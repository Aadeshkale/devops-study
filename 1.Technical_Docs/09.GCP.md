## Connectivity Services

* Cloud VPN: On-premises ↔ VPC connectivity over the public internet using IPsec 
* Cloud Interconnect: On-premises ↔ VPC connectivity through dedicated/private connectivity to Google Cloud
* VPC Peering: Private connectivity between two VPC networks using internal IPs.
* Private Google Access: Allows resources without external IPs to access Google APIs and services privately 
* Private Service Connect (PSC) : 
* * Private consumer → producer/service connectivity using private endpoints.
* *  Can be used for Google APIs, Google-managed services, and supported published services.  
* Network Connectivity Center (NCC): centralized hub-and-spoke service for connecting VPC networks and hybrid connectivity resources such as HA VPN and Cloud Interconnect.

# VPC Service Controls

* Protects Google Cloud resources from data exfiltration.
* Creates a security perimeter around one or more Google Cloud projects.
* Works in addition to IAM (does not replace it).
* Restricts access to supported Google Cloud services from outside the perimeter.
* Uses Access Context Manager to define access levels (IP, device, user, location).
* Supports Ingress (incoming) and Egress (outgoing) policies.
* Prevents copying sensitive data to unauthorized projects or networks.
* Helps protect against stolen credentials, insider threats, and misconfigurations.
* Commonly used with services like BigQuery, Google Cloud Storage, and Cloud SQL.
* Best for organizations handling sensitive or regulated data (finance, healthcare, government).

# Direct VPC egress (new way )

Purpose:
 You can enable your Cloud Run service, function, job, or worker pool to send traffic to a VPC network by using Direct VPC egress with no Serverless VPC Access connector required

* Direct VPC Egress allows serverless services like Cloud Run to directly access resources inside a VPC.
* It provides direct network connectivity without using a Serverless VPC Access Connector.
* Cloud Run → Direct VPC Egress → VPC → Cloud SQL (Private IP) is a common architecture.
* It offers lower latency and better throughput compared with VPC Connectors.
* It eliminates connector infrastructure, reducing operational complexity and additional costs.
* Recommended approach: Use Direct VPC Egress for Cloud Run when accessing Cloud SQL, GKE services, VMs, Memorystore, or other private VPC resources.

# AI ML services


## BigQuery ML

* Allows us to **build, train, evaluate, and deploy machine-learning models directly inside BigQuery using SQL**, without moving your data to a separate ML platform. It is mainly used for **tabular data** and supports algorithms such as **linear regression, logistic regression, clustering, classification, and other ML models**.


## AI Platform

* **Google AI Studio**
   * * allows us to **create and prototype AI applications and AI agents using prompts** with Gemini models. It supports **prompt templating**, prompt experimentation, multimodal inputs, and other generative AI capabilities.
* **Gemini Enterprise APP/CX**
   * * **low-code/no-code platform** that allows us to **build and use AI agents and applications** without extensive coding. It can connect AI agents to enterprise data and tools to perform business tasks. 
* ****Gemini Enterprise Agent Platform (formerly Vertex AI)**** 
   * * A unified platform to **build, deploy, scale, govern, and optimize, fine tune AI agents and ML/AI models**. It provides **Agent Studio, Agent Development Kit (ADK), Agent Runtime, Model Garden, MLOps capabilities**, and access to **200+ foundation models**.
* **Auto ML**
  * *   allows us to build custom ML models using our own data with minimal coding and ML expertise. It automates much of the **model training and evaluation process** and provides managed infrastructure for the ML workflow. The trained model can then be **deployed to an endpoint for online prediction or used for batch prediction**.
 
* **Pretrained ML API's**
  * *  Pre-trained AI APIs provide ready-to-use AI/ML capabilities that can be integrated directly into applications without building and training a model from scratch.
       Examples: Vision API → image analysis/OCR, Video Intelligence API → video analysis, Speech-to-Text, Text-to-Speech, Translation API → language translation, Natural Language API → text analysis, Document AI → document extraction/understanding.
